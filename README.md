# Тема проекта "Учёт личных финансов с категоризацией по тегам"

**Суть проекта:** 

1. Транзакции с множественными тегами, аналитика, прогнозирование.
2. **Сущности:**
    - Счёт
    - Транзакция (сумма, дата, комментарий),
    - Тег (например, "еда", "развлечения").     
3. **Фичи:**
    - Правило привязки тегов по описанию
    - Дашборд с графиками.
4. **Роли:** Пользователь.
